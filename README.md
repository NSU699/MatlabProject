# MATLAB 数值计算专题项目

这是 MATLAB 实践专题项目的课程作业仓库，选题为第七类「数值计算问题」中的第 15、16 题：

- 一维泊松边值问题 `u''(x) = exp(-x^2)` 的有限差分求解；
- 初值问题 `y'(t) = -y(t) + t^2 + 3` 的固定步长四阶 Runge-Kutta 求解，以及与解析解的比较。

项目按课程提交要求组织源程序、报告材料、结果数据和汇报材料。仓库当前仍在完善中；任何误差、收敛阶、耗时、图表和结论都必须由仓库中的 MATLAB 程序实际运行产生，不能把理论估计当作实验结果。

## 环境与运行

建议使用 MATLAB R2024a 或更新版本。公共层测试使用 MATLAB 图形功能；第 16 题的符号解析解需要 Symbolic Math Toolbox。纯数值算法应尽量提供不依赖符号工具箱的显式解析解备用路径。

在 MATLAB 当前目录切换到仓库根目录后运行：

```matlab
runAll
```

`runAll.m` 会配置 `src/` 路径并运行项目测试。算法和实验脚本完成后，仍应保持“清空工作区后从入口脚本重建结果”的可复现性。运行产生的正式数据写入 `results/`，正式图表写入 `figures/`；临时导出、解压内容和调试文件写入 `tmp/`。

单独运行公共层测试：

```matlab
addpath(genpath(fullfile(pwd, 'src')));
summary = runAllTests();
assert(summary.passed);
```
